## The Problem: pfSense on M1 Mac

**Initial Plan:** Use pfSense for firewall management

**Reality Check:** 
- ❌ pfSense is x86 architecture only
- ❌ M1 Mac is ARM64
- ❌ No compatibility

**Decision Made:** Switch to UFW (Uncomplicated Firewall)

---

## Why UFW?

- ✅ Works on M1 Mac ARM64
- ✅ Lightweight for learning
- ✅ Linux standard
- ✅ Perfect for understanding firewall fundamentals

---

## UFW Installation & Custom Rules

**Install UFW:**
```bash
sudo apt install ufw -y
```

**Enable with Default Deny Policy:**
```bash
sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing
```

**Set Custom Rules:**
```bash
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw allow 53/tcp    # DNS TCP
sudo ufw allow 53/udp    # DNS UDP
```

**Verify Rules:**
```bash
sudo ufw status verbose
```

## Result

✅ UFW firewall active with custom rules  
✅ Only ports 22, 80, 443, 53 open  
✅ All other ports blocked by default  
✅ Ready for next security layers

## What I Learned

- Not all security tools work on all architectures
- Pivot when plan doesn't fit your constraints
- Firewall principle: Default deny, explicit allow
- Each open port = potential attack surface
