# Day 1: Initial Setup & Environment Planning

## What I Did
- Created project structure and subfolders
- Downloaded Ubuntu 24.04 LTS ARM64 ISO
- Attempted pfSense setup (discovered M1 ARM incompatibility)
- Decided to use UFW (Linux firewall) instead

## Linux Concepts Learned
- `pwd` - Print working directory
- `whoami` - Current user
- `ls` - List files
- `ls -a` - List all files (including hidden)
- Permission columns (rwx, user/group/other)

## Tools Explored
- pfSense (x86 only, not compatible with M1)
- UTM (VM software for Mac)
- Ubuntu Server (ARM64 version)

## Key Decision
Pivot from pfSense to UFW firewall due to hardware constraints. This proved to be a better learning experience — understanding core firewall principles rather than GUI-based management.
