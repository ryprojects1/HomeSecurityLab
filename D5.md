Why It Failed:

I tried using PAM (Pluggable Authentication Modules) to run my MFA script after the password check. But PAM runs scripts without a proper terminal in the background, so:

My script couldn't display the security questions properly
I couldn't type my answers
The script crashed
SSH denied my access
I also had permission issues - my script couldn't read the config file because the .ssh directory was locked down.

What I Changed:

Instead of using PAM, I created a wrapper script and made it my login shell. Now here's how it works:

I SSH in and enter my password
SSH verifies it's correct ✓
SSH launches my wrapper script (still in my terminal)
The wrapper asks my 2 random MFA questions
I answer them
If I'm correct, the wrapper launches bash and I'm in ✓
Why It Works Now:

The wrapper script runs inside my active SSH session with a real terminal, so I can see the questions and type my answers normally.
